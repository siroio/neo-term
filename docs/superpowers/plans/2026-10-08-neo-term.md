# neo-term Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Windows版Emacs内でWindows CLIを操作し、C++が起動時にバックエンドを選ぶ。

**Architecture:** セッションごとのC++ EXEがConsole APIとConPTYを仲介する。ConPTY出力をlibvtermで画面状態へ変換し、従来APIの画面状態と同じフレームでEmacsへ渡す。

**Tech Stack:** C++17、Win32、libvterm 0.3.3、Emacs Lisp、MSVC、PowerShell、Python標準ライブラリ。

**Spec:** ../specs/2026-10-08-neo-term-design.md

## Global Constraints

- Windows 10 1809以降・x64、Windows版Emacs 31.1で検証する。
- winptyは使用しない。ConPTYは同梱版・システム版を実行時に読み込む。
- 既存の兄弟プロジェクトは変更しない。
- CLI起動後にはフォールバックしない。全I/Oにサイズ上限と終了経路を持つ。
- コードコメントは必要なWhy notのみ。テストは仕様、コミットログは変更理由を記す。

## Review Focus

- UTF-16のサロゲート・全角セルとUTF-8の分割が文字化けしないこと。
- コンソール初期化失敗からのフォールバックがCLIを二重起動しないこと。
- 大量出力中の入力・終了がデッドロックしないこと。
- パスの空白と引用符を含む引数が追加シェルで変形されないこと。
- プロセス通信断でヘルパーと子孫が残留しないこと。
