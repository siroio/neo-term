# シェル通知とEmacs連携

目的: プロンプトに似た出力を誤認せず、シェルとカーソルの状態をEmacsへ反映し、CLIで指定したローカルファイルを開く。

既存のC++ホスト、libvterm、Win32 Console API、Lisp描画を拡張する。新しいランタイム依存は追加しない。ConPTYはOSC 133の開始・入力位置をセルに保持し、スクロール・再配置でも位置を運ぶ。PowerShellのclassic通知はコンソール内の開始座標を明示する。古い通知の文字列照合は互換用に残す。

- [x] テスト先行でプロンプト通知とセル位置保持を追加する。
- [x] カーソル形状・点滅をnative protocolとバッファ固有の描画へ反映する。
- [x] PowerShell・cmd.exe・Git Bashの起動コードとcwd通知を追加する。
- [x] neo-openとEmacsのパス選択によるファイル・行・列の移動を追加する。
- [x] 実機・ERT・GUI・書式・独立レビューを確認し、siroioとしてコミットする。

制約: シェルの設定ファイルやレジストリは変更しない。ファイル操作はローカルパスだけを受け付け、任意のLispやシェル命令を通知から実行しない。classicが返さないVT属性や、古いConPTYが転送しないOSCの制約は明記する。
