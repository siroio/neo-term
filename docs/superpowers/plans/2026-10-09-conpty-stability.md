# ConPTY stability implementation plan

**Goal:** 大量出力の終了時に末尾を失わず、日本語・絵文字・リサイズ・割り込み・TUIを再検証し、測定した無駄な処理を減らす。

**Architecture:** 同梱の公式安定版ConPTY 1.25.260930003とWindows標準版を比較する。neo-term、ConPTY、CLIの原因を切り分け、再現テストが失敗した箇所だけを修正する。

**Constraints:** Microsoftへの提案・送信をしない。新しい製品依存を追加しない。コメントはWhy notのみ。既存の作業ディレクトリで修正し、変更をレビュー可能な状態に残す。

- [x] 大量出力後の終了で履歴の末尾が欠落するテストを追加し、両ConPTYで失敗を確認する。
- [x] `native/host.cpp` の終了判定を修正し、未送信履歴を排出する。対象テストを再実行する。
- [x] 大きい画面の待機時CPU・出力時間・入力応答を測り、不要な処理が確認できた場合は回帰テストを伴って削減する。
- [x] Unicode入出力、反復リサイズ、大量出力中のCtrl+Cと終了、実機Vimを検証する。
- [x] 全ネイティブ・CLI・ERT・GUIテストを実行し、結果と制限をREADMEへ記録する。

## Evidence

初期調査: 3000行出力の末尾は画面へ届くが、終了時に履歴の末尾が欠落した。`snapshot()` は履歴を64行ずつ渡し、ホストはCLI終了後5回の取得で終了している。

サンドボックス内のGit Bashは `NtCreateDirectoryObject` が0xC0000022で拒否された。通常権限で既存テストを再検証する。

履歴末尾のテストと大画面待機CPUのテストは、両ConPTYでRED→GREENを確認した。親終了後の連続出力子孫のテストも、両ConPTYでタイムアウトを再現し、親終了検出時のJob Object終了でGREENになった。

初回の独立レビューでは、子孫出力による終了待ちを確認し修正した。dirtyフラグの更新消失とエラー検出漏れは見つからなかった。その後の追加検証で固定の終了待ち時間を再現し、親終了後にClosePseudoConsoleを呼び、readerのEOFと未送信履歴の排出を確認する方式へ変更した。

公式パッケージは最新安定版と一致し、保存済みアーカイブのSHA256も固定値と一致した。今回再現した問題はneo-term側であり、ConPTY本体の変更・プレビュー版への更新は行っていない。

出力到着でイベントを通知し、通常の画面通知を8msでまとめる方式へ変更した。入力応答が20msのポーリング間隔で待たされるテストは両ConPTYでRED→GREENになった。固定の終了待ち時間のテストも両ConPTYでRED→GREENになった。

イベント待機へ変更したホストのベンチマーク3回: 大画面待機CPUの中央値0秒/秒、入力往復中央値8.97ms、3000行出力と終了通知の中央値0.894秒。履歴末尾は3回とも届いた。修正前はそれぞれ0.390625秒/秒、21.33ms、0.981秒で、履歴末尾は3回とも欠落した。

Windows PowerShellのConsole.Writeで日本語の後の絵文字が `??` に変換されることを両ConPTYで再現した。neo-termセッション内のコンソールとネイティブパイプ出力をBOMなしUTF-8へ変更し、テストはGREENになった。

Unicode 16の絵文字U+1FAE9でConPTYのカーソルが4、libvtermが3になる不一致と、結合文字U+1AB0が余分に1セル進む問題を再現した。公式Unicode 16.0.0から幅と結合文字の表を再生成し、両テストはGREENになった。新しい製品依存は追加していない。

公式ConPTYで修正された全角行入力のデッドロックについて、2列の画面の最終列へ全角・絵文字を入力してEnterで確定する回帰テストを追加し、同梱安定版で成功した。公式修正の1列画面と完全に同一の再現条件ではない。

追加の独立レビューでは、新たな重要な実装上の問題は見つからなかった。EOF方式と測定値のドキュメント不一致を指摘され、更新した。

最終検証: `build.ps1 -Test` 成功、ネイティブ契約・libvterm再配置成功、CLI43/43（Git Bash・実機Vimを含む、スキップなし）、ERT46/46、警告をエラーとしたbyte compile成功、GUI成功、`git diff --check` 成功。同梱EXEは最終ソースから再ビルド済み。検証ログは `build/conpty-final-test.log`。

Unicode修正後の最終EXEを3回再測定した結果は、待機CPU中央値0秒/秒、入力往復8.68ms、大量出力と終了通知0.892秒。履歴末尾は全回届いた。測定ログは `build/conpty-final-benchmark.json`。
